# Olimpia Sile Coach

App (PWA) per gli allenatori dell'Olimpia Sile: squadre, classifiche, calendari, arbitri e statistiche giocatori.

I file sono generati automaticamente da `olimpia/build_app.py` nel progetto Claude e pubblicati con GitHub Pages. Non modificarli a mano.

## Installazione

- **iPhone (Safari):** apri il link, tocca Condividi, poi "Aggiungi alla schermata Home".
- **Android (Chrome):** apri il link, menu ⋮, poi "Installa app" (o "Aggiungi a schermata Home").
